# Askonce

**The roster that learns the rules nobody wrote down.**

AI Builder Cup 2026 · Future of Work & Enterprise Productivity  
Google stack: Gemini + OR-Tools CP-SAT + Cloud Run / Firebase.

Do not pitch this as “AI scheduling.” UKG already schedules. Askonce treats every manager override as a missing constraint, asks **one** question, writes a hard rule with provenance, and re-solves.

## Desk + phone (same backend)

Do **not** clone the roster grid onto a phone. Two jobs:

| Surface | Who | Job |
|---|---|---|
| **Desk** (`/` or Desk toggle) | Nurse manager at a workstation | Generate, override, learn rules, fairness chart |
| **Phone** (`/#phone` or Phone toggle) | Manager on the floor / nurse in the break room | 23:10 yes/no ping, teach a rule by voice |
| **Side by side** | Demo / video | Hit callout on the desk → phone lights up |

Installable PWA: open `/#phone` on a phone → Add to Home Screen. That *is* the app for the submission.

## Demo (3 minutes)

1. Switch to **Side by side**.
2. **Generate roster** on the desk.
3. **Demo: Priya off Saturday** — missing-rule modal.
4. Teach `family dinner every Saturday`, re-solve.
5. **23:10 callout** — the phone pulses with who to ask and the draft WhatsApp.
6. On the phone, tap **I can cover**.
7. **Force Yamada onto nights** — refuse in English.

## Run locally

```bash
cd askonce/backend
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
uvicorn app.main:app --reload --port 8000
```

```bash
cd askonce/frontend
npm install
npm run dev
```

Open http://localhost:5173

Works without a Gemini key (heuristic question). With a key, the question and infeasibility copy are generated by Gemini.

## What is in / out of scope

**In:** override → missing rule → one question → CP-SAT → callout → legal refusal → override chart.  
**Out:** payroll, a second native codebase, 12 industries.
